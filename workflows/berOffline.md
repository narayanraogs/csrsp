# BER Offline 

* This screen is visible to users having Offline Processing privilages
* Initially show the following things to the client as a table
  * Test Phase during acquisition
  * All Previous acquired BER dates
  * All Previous acquired BER times
  * Total Time acquired
  * Remarks
* The user can filter by any field
* Work flow
  * The user selects a row and starts offline BER Plot
  * The server starts processing. 
  * Single static plot is displayed to the user which consists of all the parameter of all streams
  * There can be a maximum of 6 streams of acquisition
  * For each stream there can be a max of 6 parameters to be processed
  * The user can save the plot or take the data as a CSV
