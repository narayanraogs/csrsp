* File Based Acquisition

File based acquisition is a admin mode - available only for admins

* The screen is similar to acquisition screen all the selections are same
* In addition to that the user can also select a frame type - if this is not the source frame type, the processing will start from the middle.
* There will be also an option to provide a list of files mapping each chain in the selected frame type - which is being taken as a json as of now
* There is also an option to download the template, which only gives the keys of the json, where values are empty.
