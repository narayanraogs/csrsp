* Change the current test phase

  * Or Add a new test phase
* Change the remarks for a previous acquisition
  * This screen will be similar to the offline results screen
* Change the IP address of DAS
  * Show the user the current DAS systems and their configured IP address
  * The user can change any one and that should be reflected in the database
