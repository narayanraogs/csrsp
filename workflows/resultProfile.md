# Result Profile

Multiple results are grouped together logically to form a Result Profile

This is visible for user with Result Profile previlages

* There can be multiple result profiles in a project.
* Users can create and edit result profiles based on their need
* Delete/Update/Create Result Profile
* Delete/Update/Add a single result to the result profile
* The Result selection screen will look the same as the one in Result View. But it will be generated for all frame types in the database instead of Frame Types in the acquistion
