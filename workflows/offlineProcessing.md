# Offline Processing 

* This screen is visible to users having offline processing privilages
* Initially show the following things to the client as a table
  * Test Phase
  * Acquisition mode
  * Payload
  * Config Name
  * Remark
  * Date
  * Time
* The user can filter based on any field
* Once the user has selected a row he has to select 
  * Result Profiles
    * multiple options are available from server 
    * client has to select one of them
* Work flow
  * The user starts the processing
  * Once the processing is started the intermediate reports and subsequent steps are same as in acquisition
* Once the user has clicked a row, all the results which are generated for that acquisition id will be shown (these reports are either from initial acquistion or subsequent offline processing), the user has an option of either viewing the report or reprocessing
